Explore data without a server

            

                1. Open files, paste data, connect to a public HTTPS URL, or load the generated sample. 2. Inspect
                fields and preview. 3. Query to create a separate dataset. 4. Bind fields to a trace and Apply & render.
            

            

                For dates, select your date column as X, expand Axes, range & layout, open X axis, set Scale to
                Date, then click Apply & render. Date values must be ISO text; numeric time needs conversion using
                its units and calendar. Add traces to compare datasets; select a trace to edit its own fields and
                appearance. New chart creates an independent workspace. Longitude/latitude must be confirmed using field
                controls before map rendering; coordinates use WGS84 degrees.
            

            

                Parquet uses selected-column/row-range reads. CSV/JSON and classic NetCDF require full source reads
                (guarded at 300 MB). HDF5/NetCDF-4 is experimental: numeric root datasets, real hyperslabs, common
                packing/fill attributes; full NetCDF dimension-scale/calendar/group semantics and custom codecs are not
                guaranteed. Zarr requires an array URL or selected .zarr directory; unsupported codecs fail visibly.
                Array slices are capped at 100,000 values and chunk decoding at 300 MB.
            

            

                Remote servers must permit CORS and HTTPS; Parquet must honor byte ranges and expose Content-Length. No
                CORS proxy, credentials, tokens, analytics, or dataset storage is provided. URLs containing user
                credentials or query strings are refused to avoid saving secrets. CDN access discloses your IP to
                library hosts; initial loading requires internet. Offline CSV/JSON and Plotly may fail until their
                libraries are loaded.
            

            

                Session JSON contains references and settings, not local files or live handles. Reselect matching files
                after restore; reconnect URLs explicitly. Derived queries/slices must be rerun. Imported JavaScript is
                disabled until you edit or replace it, then explicitly Run. Scripts have full page privileges. Show-all
                is capped at 100k points; SVG exports of WebGL plots contain rasterized content. Map image export is
                unavailable.
